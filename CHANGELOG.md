# Changelog

## 1.0.0

- Five requests per IP per 24 hours without an API key, with smaller search and analysis limits.

- Ingredient search by name, synonym and CAS/EC number.
- Product search with brand and ingredient filters, pagination and product lookup.
- Ingredient lookup and INCI-list analysis.
- Typed responses containing the documented public fields.
- Credit balances and distinct errors for authentication, validation, missing records and insufficient credits.
